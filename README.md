# PFE – Municipality SDG Tracker

This project is part of my **PFE (Projet de Fin d’Études)**.  
It is a web application designed to track and visualize **Sustainable Development Goals (SDGs)** at the municipal level.

## Features
- React + Vite frontend
- Navigation bar with user name display
- Admin functionality to manage users
- Data visualization and monitoring
- Scalable structure for future SDG indicators

## Tech Stack
- React
- Vite
- JavaScript
- ESLint

## Development Notes
- Navbar fixes and UI improvements are ongoing
- A dedicated admin page will be added to manage users in the database

## React + Vite Setup
This project uses Vite for fast development with Hot Module Replacement (HMR).

Official plugins:
- `@vitejs/plugin-react` (Babel)
- `@vitejs/plugin-react-swc` (SWC)
